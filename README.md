# SORRISO MOTORS — Protótipo PWA

Protótipo inicial com cadastro de veículos, caixa geral por contas, lançamentos, transferências e backup JSON.

## Publicação

1. Extraia o ZIP e envie **os arquivos dentro da pasta** para a raiz do repositório GitHub.
2. Clique em **Commit changes**.
3. Para testar via GitHub Pages, o repositório deve permitir Pages. Em Settings > Pages, escolha Deploy from a branch, `main`, `/ (root)` e Save. **Atenção:** GitHub Pages pode exigir repositório público, dependendo do plano. Não publique dados reais.
4. Abra a URL de Pages exibida pelo GitHub e instale como aplicativo pelo navegador, se disponível.

## Limitações importantes

Os dados ficam em localStorage, no próprio navegador, sem login e sem sincronização. Não é sistema de produção. Não há backend, banco online, conciliação bancária automática, documentos anexados ou upload de fotos. O próximo passo é adicionar autenticação, banco de dados e permissões de acesso antes de uso real.
